# Installation

## Homebrew

```sh
brew install foomo/tap/dockprox
```

## Docker

```sh
docker run --rm foomo/dockprox:latest version
```

## mise

```sh
mise use github:foomo/dockprox
```

## go install

```sh
go install github.com/foomo/dockprox/cmd/dockprox@latest
```

Requires Go 1.26+.

## macOS menu bar app

A separate `dockprox-menubar` binary ships the macOS tray app — see [Menu bar app](./menubar.md).
